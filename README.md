# Expander graphs in Lean 4

> [!NOTE]
> **This code was written by AI.** The Lean source in this repository was generated by Claude
> (Anthropic), directed and reviewed by the repository owner. Every proof is checked by the Lean
> kernel, so a theorem listed as proved does follow from its stated hypotheses. What the kernel
> cannot check is whether each definition and theorem statement says what was intended. Read the
> statements before relying on them, and please open an issue if one looks wrong.

A formalization of the foundations of expander graphs and high-dimensional expanders, built on
[Mathlib](https://github.com/leanprover-community/mathlib4). Mathlib had no expander material, so
the definitions and theorems here are new.

## What is proved

| Result | Statement | File |
|---|---|---|
| Largest eigenvalue | A `d`-regular graph has largest adjacency eigenvalue `d`; all eigenvalues lie in `[-d, d]` | `Expanders/Basic.lean` |
| Courant–Fischer for `λ₂` | `λ₂ = max xᵀAx / xᵀx` over `x` orthogonal to constants | `Expanders/SymmetricSpectrum.lean`, `Expanders/Basic.lean` |
| Cheeger's inequality | `(d − λ₂)/2 ≤ h(G) ≤ √(2d(d − λ₂))` | `Expanders/Cheeger.lean` |
| The two definitions agree | A `d`-regular spectral expander with gap `δ` is a `δ/2`-edge-expander; a `d`-regular `ε`-edge-expander is a spectral expander with gap `ε²/(2d)` | `Expanders/Cheeger.lean` |
| Worked example: the hypercube | The `n`-cube has spectral gap exactly `2` and Cheeger constant exactly `1`, so the lower bound in Cheeger's inequality is attained | `Expanders/Hypercube.lean` |
| Alon–Boppana bound | Large `d`-regular graphs have `λ₂ ≥ 2√(d−1) − ε` | `Expanders/AlonBoppana.lean` |
| Trickling down (Oppenheim) | Expansion of the smallest links of a pure, connected complex forces expansion of every link. Proved for arbitrary positive weights on the top faces; the uniformly weighted statement is a corollary | `Expanders/WeightedComplex.lean`, `Expanders/TricklingDown.lean`, `Expanders/TricklingDownSpectral.lean` |
| Lower bound on link eigenvalues | Every eigenvalue of the walk on the link of `σ` in a `d`-dimensional weighted complex is at least `−1/(d − |σ|)` | `Expanders/WeightedComplex.lean` |
| Configuration model | Every `d`-regular graph on `n` labelled vertices arises from exactly `(d!)ⁿ` simple pairings, and its edge boundaries are counted by crossing pairs | `Expanders/ConfigurationModel.lean` |
| Almost every regular graph is an expander | For `d ≥ 3` there is `ε > 0` such that the proportion of `d`-regular graphs on `n` labelled vertices that are `ε`-edge-expanders tends to `1`; hence arbitrarily large `d`-regular expanders exist | `Expanders/Existence.lean` |
| Random pairings expand | For `d ≥ 3`, the proportion of pairings with a vertex set `S` crossed by fewer than `|S|/1000` pairs tends to `0` (first-moment count plus binomial estimates) | `Expanders/ConfigurationModelExpansion*.lean`, `Expanders/ConfigurationModelBinomial.lean` |
| Simple pairings are common | For `n ≥ 8d + 8`, at least an `exp(−(4d + 8d²))` fraction of all pairings are simple (switching argument) | `Expanders/ConfigurationModelSwitching.lean`, `Expanders/ConfigurationModelSimple.lean` |
| Second eigenvalue of a weighted graph | For symmetric nonnegative weights with positive degrees, the variational bound is exactly a bound on the second eigenvalue of the symmetrised random-walk matrix | `Expanders/WalkSpectrum.lean` |
| Worked example | All triangles on five points satisfy every hypothesis of trickling down; the resulting bound `−1/4` on the underlying graph is sharp | `Expanders/CompleteComplex.lean` |

Nothing. There is no `sorry` in the repository, and CI enforces that on every push.

## Definitions

- **Edge expansion**: `SimpleGraph.edgeBoundary`, the Cheeger constant `SimpleGraph.edgeExpansion`,
  and `SimpleGraph.IsEdgeExpander`.
- **Spectral expansion**: `SimpleGraph.adjEigenvalues`, `SimpleGraph.spectralGap`,
  `SimpleGraph.IsSpectralExpander` (a notion for regular graphs only, since an adjacency gap does
  not certify expansion otherwise), and `SimpleGraph.IsRamanujan` (connected, with eigenvalues
  `±d` exempt).
- **High-dimensional expanders**: links of Mathlib's `PreAbstractSimplicialComplex`, purity,
  connectivity, top-face weights (`IsTopWeight`), the weighted graph of a link (`linkWeightOf`,
  and `linkWeight` for uniform weights), and `IsLocalSpectralExpander` /
  `IsLocalSpectralExpanderOf`: a pure complex of dimension at least 1, with at least one face, in
  which every link has small second eigenvalue. Expansion is one-sided throughout: only the second-largest eigenvalue
  is bounded from above.
- **Weighted graphs**: `WalkSecondEigenvalueLE`, the second eigenvalue of the random walk in
  variational form, used because links are weighted and not regular.

## Build and verify

```
lake exe cache get   # download the Mathlib build cache
lake build
lake env lean Audit.lean
```

`Audit.lean` fails if any declaration in the project is an axiom or uses `sorry`, and it fails
if any of the headline theorems it lists depends on anything beyond Lean's three standard axioms
(`propext`, `Classical.choice`, `Quot.sound`). CI runs the build and the audit on every push.

Requires Lean 4.33.1 and Mathlib `v4.33.1`, pinned in `lean-toolchain` and `lake-manifest.json`.
